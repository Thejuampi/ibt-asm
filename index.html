01 / TEST YOUR OVERCLOCK

Push it hard.
Check every run.

GFLOPS shows how fast the workload ran. To check stability, IBT compares the numerical result of each completed run. If one differs, your setup failed this check.

How IBT determines stability ↗
01 / CONFIGURE

Choose your stress level.

Set the memory load, run count, and threads for the overclock you want to check.

02 / STRESS

Put the CPU to work.

IBT drives a sustained numerical workload through the best supported SSE2, AVX, or AVX2 path.

03 / VERIFY

Catch a bad run.

The first completed run sets the reference. Every later run must produce the same signature to pass.

02 / SEE THE VERDICT

Know when
a run disagrees.

Watch run progress, speed, and the result in one window. A pass appears only after every requested run completes with a matching signature; stopping early does not count.

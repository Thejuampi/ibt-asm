02 / RUN A USEFUL CHECK

Test the tune
you plan to use.

Choose a workload, watch temperatures, and let every requested run finish. You can start small and increase pressure as you tune.

01

Get ready for heat.

Check your cooling, close unnecessary apps, and keep a temperature monitor open during the test.

02

Set the workload.

Choose stress level, run count, and threads. For CPU tuning, High · 10 runs · All threads is one suggested starting point.

03

Run it to completion.

Press Start and wait for the verdict. If IBT finds a mismatch, adjust the setup and test again.

Suggested settings are starting points, not universal pass criteria. Increase duration and memory pressure gradually. See all stress levels ↗

03 / READ THE VERDICT

A pass is earned
run by run.

The first completed run sets a reference signature. Every later run must match it. GFLOPS reports speed; the matching results determine the stability verdict.

PASS

All runs match.

Every requested run completed with the same signature under this workload.

FAILURE

A run disagrees.

A numerical mismatch or unexpected termination was detected. Revisit the setup before relying on it.

STOPPED

No stability verdict.

The test ended before all requested runs completed, so it cannot count as a pass.

A pass shows repeatable results under this workload. It cannot guarantee stability in every application or workload.

04 / UNDER THE HOOD

What IBT runs
on your CPU.

The Windows and Linux builds share one x86-64 assembly numerical core. Each has a native interface; the test workload stays the same.
